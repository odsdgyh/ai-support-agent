# PolyAssist AI — 3D Pipeline & Game Dev Support Agent

**PolyAssist AI** — инженерный ИИ-ассистент в эстетике **Brutalism Website Style** для **3D-моделирования**, **цифрового скульптинга** и **Game Dev**. Работает напрямую через клиентский ключ Google AI Studio (**BYOK — Bring Your Own Key**) без серверного прокси.

---

## Возможности

- **3 профильные 3D-дисциплины (System Prompts)**:
  - `3D Modeling` — квад-топология, устранение N-гонов и полюсов, support loops под Subdivision Surface, UV-развёртка и скрипты `bpy`.
  - `3D Sculpting` — пайплайн Dynamesh → ZRemesher → Subdivision, запекание карт нормалей/смещения (MikkTSpace, 32-bit EXR), анатомия и силуэт.
  - `Game Dev` — оптимизация Draw Calls, Nanite / Lumen, GPU Instancing, LOD и математика шейдеров HLSL / GLSL.
- **Строгий тематический фильтр (Strict 3D Guardrail)**:
  - Отвечает исключительно на вопросы по 3D, текстурированию, рендеру и разработке игр. Нецелевые запросы и попытки промпт-инъекций отклоняются без засорения истории диалога.
- **Мультимодальная диагностика (Vision)**:
  - Прикрепление до 3 скриншотов (`PNG`, `JPEG`, `WebP`) сетки вьюпорта, UV-развёртки или графа нод шейдера.
- **Светлая и тёмная темы (`Light` / `Dark`)**:
  - Мгновенное переключение между *Swiss Paper Brutalism* и мягкой тёмной палитрой *Dark Industrial* (`⌘J` / `Ctrl+J`).
- **Двуязычный интерфейс (`RU` / `EN`)**:
  - Полная локализация интерфейса и быстрых промптов на русский и английский языки в 1 клик.
- **Zero-Trust BYOK Vault**:
  - Поддержка ключей Google AI Studio форматов `AQ.…` и `AIza…`, хранение в `sessionStorage` по умолчанию и строгая политика `Content-Security-Policy`.

## Быстрый старт

```bash
# Запуск локального сервера
npx http-server -p 8080 -c-1 .

# Запуск модульных тестов (Node.js 20+)
npm test
```

Откройте `http://127.0.0.1:8080`, нажмите **`[⌘K]`** (или кнопку **Подключить ключ / Connect Key**), вставьте свой ключ Google AI Studio и выберите нужную 3D-специализацию.
