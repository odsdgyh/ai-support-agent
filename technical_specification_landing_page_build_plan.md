# Техническая спецификация (Tech Spec) и план сборки: PolyAssist AI

**Основано на:** PRD PolyAssist AI v1.0  
**Версия спецификации:** 1.0  
**Целевые модели ИИ:** Gemini 3.5, Gemini 3.6, Gemini 3.8 (Google AI Studio API)  
**Тематика продукта:** 3D-моделирование, 3D-скульптинг и разработка игр (Game Dev)  

---

## Часть 1. Техническая спецификация (System Specification)

### 1.1. Архитектурный обзор
Система **PolyAssist AI** строится по гибридной схеме **BYOK (Bring Your Own Key)**:
1. **Клиентский уровень (Single-Page / Landing App):** Обеспечивает презентацию продукта, регистрацию пользователя, управление локальным или облачным хранилищем API-ключа (`AIzaSy...`), переключение между моделями (**Gemini 3.5 / 3.6 / 3.8**) и интерфейс мультимодального чата.
2. **Уровень API-прокси / Маршрутизатора:** Принимает запросы от клиента, подставляет системный промпт выбранной 3D-дисциплины и перенаправляет запрос в **Google AI Studio (`generativelanguage.googleapis.com`)** с использованием ключа пользователя.

$$\text{Client UI} \xrightarrow{\text{Payload + User API Key}} \text{Model Router (3.5 / 3.6 / 3.8)} \xrightarrow{\text{System Prompt + Context}} \text{Google Gemini API}$$

| Выбранная версия | Идентификатор модели в системе | `temperature` | `maxOutputTokens` | Основное назначение в 3D-пайплайне |
| :--- | :--- | :---: | :---: | :--- |
| **Gemini 3.5** | `gemini-3.5-flash` / `gemini-3.5` | $0.3$ | $2048$ | Быстрые справки по хоткеям Blender/Maya/ZBrush, базовые скрипты (`bpy`). |
| **Gemini 3.6** | `gemini-3.6-pro` / `gemini-3.6` | $0.4$ | $4096$ | Анализ скриншотов сетки (wireframe), UV-разверток и узлов Shader Graph. |
| **Gemini 3.8** | `gemini-3.8-ultra` / `gemini-3.8` | $0.2$ | $8192$ | Глубокая математика шейдеров (HLSL/GLSL), архитектура C++/C# и оптимизация рендера. |

### 1.3. Системные промпты по специализациям (Domain System Prompts)

При отправке сообщения агент автоматически инжектирует системную инструкцию в зависимости от выбранного режима:

* **Режим `3D Modeling` (Моделирование и топология):**
  > *"Ты — старший технический 3D-художник по полигональному моделированию (Blender, Maya, 3ds Max). Фокусируйся на чистой квад-топологии, устранении N-гонов и полюсов на изогнутых поверхностях, правильной расстановке поддерживающих лупов (support loops) под Subdivision Surface и упаковке UV-островов с равномерным тексельным разрешением (Texel Density)."*
* **Режим `3D Sculpting` (Цифровой скульптинг):**
  > *"Ты — ведущий цифровой скульптор (ZBrush, Mudbox, Nomad Sculpt). Помогай с пайплайном Dynamesh, ZRemesher, проекцией деталей с High-Poly на Low-Poly, настройкой 32-битных карт смещения (EXR Displacement) и анатомическими пропорциями."*
* **Режим `Game Dev` (Игровые движки и шейдеры):**
  > *"Ты — Principal Technical Artist и программист графики (Unreal Engine 5, Unity, Godot). Фокусируйся на оптимизации Draw Calls, настройке Nanite/Lumen, запекании нормалей в пространстве MikkTSpace, написании кода на C#/C++ и математических формулах шейдеров HLSL/GLSL (например, $I = \max(0, N \cdot L)$)."*

### 1.4. Структура данных и хранение API-ключа (BYOK Vault)

#### Схема объекта профиля пользователя (`LocalStorage` / БД):
```json
{
  "userId": "usr_982341",
  "username": "PolySculptor_99",
  "preferredModel": "Gemini 3.8",
  "defaultDomain": "3D Modeling",
  "apiKeyConfig": {
    "provider": "google_ai_studio",
    "encryptedKey": "U2FsdGVkX1+vupppZksvRf5pq5g5...",
    "keyPrefix": "AIzaSy...",
    "isVerified": true,
    "lastVerifiedAt": "2026-11-03T15:30:00Z"
  }
}
```

#### Алгоритм валидации API-ключа Google AI Studio:
1. Проверка формата регулярным выражением: `^AIza[0-9A-Za-z\-_]{35}$` (или базовая проверка префикса `AIzaSy` и длины $\ge 30$ символов).
2. Выполнение тестового легковесного запроса (`models.list` или `generateContent` с 1 токеном) к эндпоинту Google AI Studio.
3. При ответе `HTTP 200 OK` статус меняется на `Key Connected` (зеленый индикатор в UI). При `400/403` выводится ошибка невалидного ключа.

### 1.5. Контракт вызова ИИ-агента (API Request / Response)

**Запрос от фронтенда к маршрутизатору агента:**
```json
{
  "model": "Gemini 3.8",
  "domain": "Game Dev",
  "apiKey": "AIzaSy...",
  "messages": [
    {
      "role": "user",
      "content": "Напиши формулу Fresnel rim-свечения для HLSL шейдера.",
      "attachments": []
    }
  ]
}
```

**Формат ответа:**
```json
{
  "status": "success",
  "modelUsed": "Gemini 3.8",
  "domain": "Game Dev",
  "reply": "Вот реализация эффекта Френеля на HLSL...",
  "usage": {
    "promptTokens": 64,
    "completionTokens": 142,
    "totalTokens": 206
  }
}
```

## Часть 2. План по сборке лендинга и интеграции агента (Landing Page Build Plan)

Лендинг собирается по принципу **Single-File Architecture** (единый самодостаточный файл `index.html`, включающий разметку, Tailwind CSS, SVG-графику 3D-вьюпорта и клиентскую логику).

### Этап 1: Настройка дизайн-системы и окружения (UI Foundation)
* **Задача 1.1:** Подключить Tailwind CSS и шрифты `Inter` (основной UI) + `JetBrains Mono` (код, шейдеры, параметры полигонажа).
* **Задача 1.2:** Настроить цветовую палитру темной темы 3D-редактора:
  * Фон вьюпорта: `#090b10` с процедурной CSS-сеткой (`viewport-grid`, шаг $40\times40\text{ px}$).
  * Акцентные цвета по дисциплинам: Индиго (`#6366f1` — 3D Modeling), Циан (`#06b6d4` — 3D Sculpting), Изумрудный (`#10b981` — Game Dev).
* **Задача 1.3:** Создать эффекты матового стекла (`backdrop-filter: blur(12px)`) и плавающую CSS-анимацию (`@keyframes floatSlow`) для карточек.

### Этап 2: Сборка структурных секций лендинга (Layout & Content)
* **Задача 2.1: Sticky Header (Навигация и статус ключа):**
  * Логотип с иконкой 3D-каркаса куба и бейджем `Gemini 3.5 / 3.6 / 3.8`.
  * Динамический индикатор состояния ключа (`No API Key Connected` с янтарным пульсирующим маркером $\rightarrow$ меняется на зеленый `Key Connected` после ввода ключа).
  * Кнопка вызова модального окна регистрации и привязки ключа.
* **Задача 2.2: Hero-секция с имитацией 3D-вьюпорта:**
  * Левая колонка: Оффер, CTA-кнопки быстрого перехода к агенту и подключения ключа, плашки поддерживаемого ПО (Blender, Maya, ZBrush, Unreal 5, Unity, Godot).
  * Правая колонка: Интерактивный макет окна `Viewport_Diagnostic.blend` с индикаторами осей (`X`, `Y`, `Z`), счетчиком треугольников (`Tris: 14,280 | Quads: 100%`), векторной SVG-сеткой меша и примером вердикта от **Gemini 3.8**.
* **Задача 2.3: Секция «3 столпа 3D-пайплайна» (`#disciplines`):**
  * 3 карточки с детальными кейсами: *3D Modeling & Topology*, *3D Digital Sculpting*, *Game Dev & Shaders*.

### Этап 3: Разработка интерактивного модуля ИИ-агента (`#workspace`)
* **Задача 3.1: Панель управления агентом:**
  * Кнопки-переключатели версии модели: `Gemini 3.5`, `Gemini 3.6`, `Gemini 3.8 ★` с мгновенным обновлением описания возможностей модели.
  * Выпадающий список (`<select>`) выбора специализации: *3D Modeling*, *3D Sculpting*, *Game Dev*.
* **Задача 3.2: Окно чата и быстрые пресеты (`Quick Prompts`):**
  * Контейнер истории сообщений с автоскроллом и поддержкой форматирования блоков кода (`<pre><code>`).
  * 3 кнопки-пресета для тестирования в один клик (артефакты после Boolean в Blender, швы карт нормалей между ZBrush и UE5, формула Fresnel-шейдера).

### Этап 4: Секция-гайд по Google AI Studio и Модальное окно BYOK
* **Задача 4.1: Визуальный гайд из 3 шагов (`#api-guide`):**
  * Карточки «Шаг 01: Открыть Google AI Studio», «Шаг 02: Скопировать ключ `AIzaSy...`», «Шаг 03: Сохранить в профиле».
* **Задача 4.2: Модальное окно регистрации и хранилища ключей (`#apiKeyModal`):**
  * Поля ввода: Никнейм 3D-художника/разработчика, выбор модели по умолчанию (`3.5 / 3.6 / 3.8`), поле ввода API-ключа (`type="password"`).
  * Сохранение данных в `localStorage` (`polyassist_user`, `polyassist_key`, `polyassist_model`) с автоматическим восстановлением сессии при перезагрузке страницы.
